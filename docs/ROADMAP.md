# Roadmap

## Phase 0: Foundation and Docs

Create the repository foundation, documentation, folder structure, Rainy Cafe placeholder theme, and first playable static game screen.

## Phase 1: Offline Chess Board

Improve local chess interactions, move history, status states, legal move display, reset flow, and basic polish.

## Phase 2: Rainy Cafe Visual Shell

Replace CSS placeholders with modular Rainy Cafe assets for background, panels, board frame, buttons, avatars, decor, and particles.

## Phase 3: Asset-Based Theme System

Strengthen the theme pack model so new themes can be dropped in without rewriting game components.

## Phase 4: Local Play Polish

Add gentle end-game feedback, better move sounds, accessible controls, responsive tuning, and visual highlights.

## Phase 5: Private Room Multiplayer

Add private room codes or links, white/black assignment, synchronized moves, reconnect planning, and server-side validation.

## Phase 6: Puzzle and Teaching Mode

Add beginner FEN-based puzzles, hints, explanations, and soft feedback.

## Phase 7: Shop and Customization

Add cosmetic inventory concepts, theme unlock previews, avatar frames, table decor, board frames, and piece sets.

## Phase 8: Animations, Sounds, and Polish

Add theme-specific particles, ambient sound packs, move animations, transitions, and cozy presentation details.

## Phase 9: More Themes

Add Snowy Cabin, Heart Room, Bakery Room, Ocean Room, Night Room, Sakura Tea House, Mushroom Forest, Honey Garden, Autumn Library, and Stargazing Observatory.
