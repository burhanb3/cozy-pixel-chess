# Rainy Cafe Rebuild V2 Typography

Date: 2026-05-17

## Goal

Make live HTML text feel closer to the approved Rainy Cafe reference without baking dynamic text into image assets.

## Direction

- Use heavier, rounder, game-like UI text.
- Keep labels short and centered in their frames.
- Use warm cream text on dark controls.
- Use dark coffee text on parchment panels.
- Add subtle pixel-style shadow/outline so text feels printed into the UI.
- Avoid modern web spacing, thin weights, and generic table headings.

## Treatments

Turn plaque:
- large dark coffee text
- cream shadow/highlight
- aligned like a wooden sign label

Player cards:
- player name larger and darker
- side label small uppercase
- rating/timer pills compact and visually secondary
- status line short and tucked into the card

Move history:
- title mixed case, not table-like
- rows compact with number, white move, black move
- latest row can use warm green/gold highlight
- no `WHITE` / `BLACK` headers

Buttons:
- live labels remain dynamic
- labels sit at the lower third of button skins
- cream text with dark outline/shadow

Quote:
- centered in banner
- dark coffee text
- enough side padding to avoid floral edges

Coach bubble:
- short wrapped text
- dark coffee text
- no instructional UI copy

Coordinates:
- either embedded in the reference-derived board frame or rendered as warm cream text with dark shadow at frame positions
- must not look like browser overlay text floating outside the board
