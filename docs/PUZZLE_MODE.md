# Puzzle Mode

Puzzle mode should be beginner-friendly and gentle.

## Plan

- Store puzzles as FEN-based data.
- Validate correct moves with `chess.js`.
- Start with a tiny set of beginner puzzles.
- Show gentle hints before revealing answers.
- Use soft explanations after each move.
- Avoid harsh language like "wrong", "blunder", or "failed".
- Add a future daily puzzle only after the basic mode is pleasant and stable.

Puzzle mode is intentionally not implemented in the foundation task.
